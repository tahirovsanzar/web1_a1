# Experience Fitness Astana - Web Technologies Assignment 2

A front-end web development project creating a dark-themed fitness club website for Experience Fitness in Astana. This project demonstrates raw HTML and CSS capabilities without the use of any external frameworks or libraries.

## Team Members
* Sanzharbek Takhirov (index.html, about.html, gallery.html)
* Meyirzhan Zhaumytbay (services.html, booking.html)
* Bekzhat Kaliev (trainers.html, contact.html, colophon.html)

## Technologies Used
* Semantic HTML5
* Advanced CSS3 (Flexbox, Grid Layout, Custom Positioning)

## Features
* Fully custom dark mode CSS theme
* Grid-based service and team layouts
* Flexbox navigation and form alignments
* Strict adherence to W3C validation standards
