# Experience Fitness Astana - Student Project

This repository contains the website for "Experience Fitness Astana," developed as a multi-page HTML/CSS student project.

## Assignment 3 Updates: Bootstrap 5.3 Migration
For this assignment, the entire project was refactored to integrate **Bootstrap 5.3**, replacing the legacy custom layouts.

**Key improvements include:**
* **Responsive Layout:** Replaced custom CSS grids and flexbox implementations with Bootstrap's responsive Grid system (`.row`, `.col-md-6`, etc.).
* **Framework Components:** Implemented the Bootstrap responsive Navbar (with hamburger menu), styled Cards for the gallery and trainers sections, and updated all forms using `.form-control` and `.form-select`.
* **CSS Cleanup:** Conducted a massive CSS cleanup. Removed all conflicting custom CSS rules (such as manual floats, absolute positioning, custom flex containers, and `!important` tags) to ensure strict adherence to the Bootstrap framework.
* **Inline Styles Removed:** Eliminated all hardcoded inline styles from the HTML documents.
