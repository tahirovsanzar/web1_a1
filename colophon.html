How this website was made

Project method

This website was built as a set of local HTML files. Every page uses the same semantic structure: a header for the site identity, a nav list for links, main for page content and a footer for contact details. The browser reads the document type declaration first, then interprets the HTML elements and creates the page shown on screen. No CSS, JavaScript, framework or template is used in this version.

We chose section to group related information, article for independent pieces such as class descriptions, and aside for supporting advice. These elements explain the meaning of the content better than a generic div. When a visitor presses a submit button, the browser prepares the form values according to the method and action attributes. At present the forms do not send data because this project has no server-side program.

<main>
  <h1>Page title</h1>
  <section>Useful content</section>
</main>

Use Ctrl + R to refresh a local page. A successful validation result may say Document checking completed. No errors found.
