Project Method & Validation

This website was built as a set of local HTML files. Every page uses the same semantic structure: a <header> for the site identity, a <nav> list for links, <main> for page content, and a <footer> for contact details. The browser reads the document type declaration first, then interprets the HTML elements and creates the page shown on screen. No external CSS frameworks, JavaScript, or templates are used in this version. The design is built entirely with custom CSS.

We chose <section> to group related information, <article> for independent pieces such as class descriptions, and <aside> for supporting advice. These elements explain the meaning of the content better than a generic <div>. A basic structure in our project looks like this:


<main>
  <h1>Page title</h1>
  <section>Useful content</section>
</main>

During development, we load the files in a browser and use Ctrl + R to refresh a local page and view updates. Furthermore, all pages have been tested for correct W3C HTML5 semantics. A successful validation result on our pages confirms the code quality, stating: "Document checking completed. No errors found." At present, when a visitor presses a submit button, the forms do not send data because this project has no server-side program.
