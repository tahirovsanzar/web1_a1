About the Project

This website was developed as a Midterm Project for the Web Technologies course by Tahirov Sanzharbek, Meirzhan Zhaumytbay, and Bekzat Kaliev. It represents a functional, responsive front-end interface for "Experience Fitness Astana".

Technologies Used

  • HTML5: Semantic structure and form inputs prepared with unique IDs for future JavaScript integration.
  • CSS3: Custom base styling for typography and animations.
  • Bootstrap 5.3: Utilized via CDN for the responsive grid system, navigation bar, cards, and utility classes (e.g., text-danger, bg-black).

Design Choices

The color palette relies on a dark theme (`bg-dark`, `bg-black`) contrasted with red highlights (`danger` theme in Bootstrap) to convey energy and action, fitting for a fitness club.
